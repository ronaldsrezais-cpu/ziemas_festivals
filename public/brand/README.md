# Latvijas skolu Ziemas festivāla zīmola elementi

SVG elementi iegūti no lietotāja iesniegtās zīmola grāmatas `Ziemas_festivals_zimola_gramata(1).pdf`.

- `logo-color.svg` — horizontālais krāsainais logo gaišam fonam.
- `logo-white.svg` — horizontālais baltais logo tumšam fonam.
- `symbol.svg` — festivāla simbols.
- `winter-pattern.svg` — oriģinālais sporta veidu grafiskais raksts.

Saglabājiet logo proporcijas. Neizstiepiet un nepārzīmējiet logo vai simbolu.
